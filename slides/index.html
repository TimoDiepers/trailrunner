trailrunner

Life cycle inventories built by traversing computational process models. Every product, flow, unit and condition is an IRI from the sentier vocabulary.

$ trailrunner run https://vocab.sentier.dev/products/bonsai/2025.1/BONSAI2025.1/fi_37440 \ --amount 1 --unit https://vocab.sentier.dev/units/unit/TONNE \ --location DK --time 2030-06-15 \ --context-tolerance "https://vocab.sentier.dev/units/quantity-kind/Pressure=0:1e5 https://vocab.sentier.dev/units/unit/PA" \ --models examples/showcase_models.py

A static unit process answers for one region, one year and one set of conditions. trailrunner computes the answer for this demand, by asking models that compute theirs.

A demand reaches whichever model produces its IRI, with no name matching. Ask for another location, time or pressure and the model computes a different result.

03 the idea

One loop builds the supply chain

Without an exact match, the chain falls back one step at a time.

04 example

The cement plant model

trailrunner/models/cement.py (abridged)
CEMENT      = "https://vocab.sentier.dev/products/bonsai/2025.1/BONSAI2025.1/fi_37440"
NATURAL_GAS = "https://vocab.sentier.dev/products/bonsai/2025.1/BONSAI2025.1/fi_12020"
CO2_FOSSIL  = "https://vocab.sentier.dev/flows/co2-fossil"
PRESSURE    = "https://vocab.sentier.dev/units/quantity-kind/Pressure"

class CementPlant(Model):
    produces = [CEMENT]
    coverage = Coverage(time_range=year_range(2026, 2050), units=frozenset({KG}))

    def apply(self, demand):
        row = self.params.at(location=demand.flow.location, **when(demand.flow))          # 1
        penalty = moisture_penalty(row["moisture"], row["temperature"])                  # 2
        clinker = row["clinker_factor"] * demand.amount
        fuel = row["fuel_demand"] * clinker * penalty
        return Result(
            production=[Exchange(flow=demand.flow, amount=demand.amount, unit=demand.unit)],
            technosphere=[Demand(flow=self._gas(here(NATURAL_GAS)), amount=fuel, ...), ...],   # 3
            biosphere=[Exchange(flow=here(CO2_FOSSIL), amount=CLINKER_CALCINATION_CO2 * clinker, unit=KG),
                       Exchange(flow=here(CO2_FOSSIL), amount=GAS_CO2_PER_MJ * fuel, unit=KG)],   # 4
        )
1Parameters by place and time from a trailpack parquet
2Physics. Damp, cold air costs fuel
3Gas at the burner pressure, returned as a new demand
4Calcination and combustion CO₂ kept apart

06 example

Hand the demand to the orchestrator

examples/showcase.ipynb
tier1 = ModelProvider(Glossary(MODELS))                                      # models, exact match
PROXY = ProxySettings(context_tolerance={PRESSURE: (0.0, 1e5, PA)})               # up to 1e5 Pa higher, never lower
tier2 = GeneralisingProvider(tier1, settings=PROXY, hierarchy=HIERARCHY, taxonomy=taxonomy)
tier3 = BackgroundProvider(pack)                                             # background datasets

report = Orchestrator(ResolutionChain([tier1, tier2, tier3])).calculate(DEMAND)
print(report.summary())

10 summary
  • 01Products, flows, units and conditions are sentier vocabulary IRIs. Models connect through them.
  • 02Processes compute their exchanges from location, time and conditions.
  • 03Every fallback and cutoff is recorded where it happens.
  • 04Inventories are time-explicit by construction.
