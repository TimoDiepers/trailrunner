# Example Models

Direct air capture: the worked example. Sorbent regeneration heat is not a fixed coefficient - colder, drier air means less CO<sub>2</sub> and less water reaching the sorbent per unit of air moved. That dependency is the reason a model is Python code rather than a row in a table.
